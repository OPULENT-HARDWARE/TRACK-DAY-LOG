A public record of every track day, autocross, and lap.

**Live site:** https://[yourusername].github.io/track-day-log/

## Structure

```
track-day-log/
├── index.html                              ← Main log index
└── 2026-06-18-thunderhill-east/
    └── index.html                          ← Thunderhill East, June 2026
```

## Adding a new event

1. Create a folder: `YYYY-MM-DD-venue-name/`
2. Drop the compressed `index.html` inside
3. Add an entry card to the root `index.html`
4. Push — GitHub Pages deploys automatically

## Upcoming events

Pulled live from Google Sheets every 5 minutes. Update the sheet to update the site.
